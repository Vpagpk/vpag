# VPAG - Visual Portfolio & Admin Gallery

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/vpag)

A modern, high-performance Next.js application optimized for Vercel deployment with built-in admin panel, authentication, and gallery management.

## 🚀 Quick Deploy

**Deploy to Vercel in one click** → [Deployment Guide](./DEPLOY_TO_VERCEL.md)

## ✨ Features

- 🎨 Modern, responsive design with dark mode
- 🔐 Secure authentication with Better Auth
- 📸 Gallery management with Vercel Blob storage
- 📊 Admin dashboard with analytics
- ⚡ Optimized for Vercel Edge Network
- 🎯 Built-in SEO optimization
- 📈 Vercel Analytics & Speed Insights

## 🛠️ Tech Stack

- **Framework**: Next.js 15 with App Router
- **Database**: Turso (LibSQL)
- **Authentication**: Better Auth
- **Storage**: Vercel Blob
- **Styling**: Tailwind CSS v4
- **UI Components**: Radix UI + shadcn/ui
- **Deployment**: Vercel (optimized)

## 📋 Getting Started

### Local Development

```bash
# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see your application.

See [DEPLOY_TO_VERCEL.md](./DEPLOY_TO_VERCEL.md#-setting-up-environment-variables) for detailed setup instructions.

- Production console removal
