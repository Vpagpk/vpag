## 📋 Prerequisites

Before deploying, ensure you have:

1. **GitHub Account** - Your code should be in a GitHub repository
2. **Vercel Account** - Sign up at [vercel.com](https://vercel.com)
3. **Turso Database** - Create a database at [turso.tech](https://turso.tech)
4. **Environment Variables** - See configuration below

## 🎯 One-Click Deployment

### Step 1: Click the Deploy Button

Click the "Deploy with Vercel" button above. This will:
- Clone your repository to your Vercel account
- Prompt you for required environment variables
- Automatically configure build settings
- Deploy your application

### Step 2: Configure Environment Variables

You'll be prompted to enter these variables:

| Variable | Description | Example |
|----------|-------------|---------|
| `TURSO_CONNECTION_URL` | Your Turso database connection URL | `libsql://your-db.turso.io` |
| `TURSO_AUTH_TOKEN` | Your Turso authentication token | `eyJhbGc...` |
| `BETTER_AUTH_SECRET` | Secret key for authentication (32+ chars) | `your-super-secret-key-here` |
| `NEXT_PUBLIC_SITE_URL` | Your deployed site URL | `https://your-app.vercel.app` |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob storage token | Auto-generated by Vercel |

### Step 3: Deploy!

Click "Deploy" and wait 2-3 minutes for your first deployment to complete.

## 🔧 Manual Deployment (Alternative)

If you prefer manual deployment:

### Via Vercel Dashboard

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import your Git repository
3. Vercel will auto-detect Next.js settings:
   - **Framework**: Next.js
   - **Build Command**: `npm run build`
   - **Output Directory**: `.next`
   - **Install Command**: `npm install`
4. Add environment variables (see table above)
5. Click "Deploy"

### Via Vercel CLI

```bash
# Install Vercel CLI
npm i -g vercel

# Login
vercel login

# Deploy to preview
vercel

# Add environment variables
vercel env add TURSO_CONNECTION_URL
vercel env add TURSO_AUTH_TOKEN
vercel env add BETTER_AUTH_SECRET
vercel env add NEXT_PUBLIC_SITE_URL
vercel env add BLOB_READ_WRITE_TOKEN

# Deploy to production
vercel --prod
```

## 🔐 Setting Up Environment Variables

### 1. Turso Database

```bash
# Install Turso CLI
curl -sSfL https://get.tur.so/install.sh | bash

# Create database
turso db create vpag

# Get connection URL
turso db show vpag --url

# Create auth token
turso db tokens create vpag
```

### 2. Better Auth Secret

Generate a secure random string (32+ characters):

```bash
# Using OpenSSL
openssl rand -base64 32

# Using Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

### 3. Site URL

After first deployment, update `NEXT_PUBLIC_SITE_URL` with your actual Vercel URL:
- Go to your project settings in Vercel
- Navigate to "Environment Variables"
- Update `NEXT_PUBLIC_SITE_URL` to your production domain

### 4. Vercel Blob Token

The `BLOB_READ_WRITE_TOKEN` is automatically created when you:
1. Go to your project in Vercel Dashboard
2. Navigate to "Storage" → "Create Database" → "Blob"
3. The token will be automatically added to your environment variables

After first deployment, run migrations:

```bash

vercel env pull .env.local
npm run db:push
```

Or use Turso CLI:


## 🐛 Troubleshooting

### Build Fails

**Issue**: Build fails on Vercel
**Solution**: 
- Ensure all environment variables are set
- Check build logs for specific errors
- Verify Node.js version compatibility

### Database Connection Errors

**Issue**: Can't connect to Turso database
**Solution**:
- Verify `TURSO_CONNECTION_URL` and `TURSO_AUTH_TOKEN` are correct
- Ensure Turso database is accessible from Vercel's edge network
- Check database is not paused (free tier limitation)

### Images Not Loading

**Issue**: Images fail to load or upload
**Solution**:
- Verify `BLOB_READ_WRITE_TOKEN` is set correctly
- Check Vercel Blob storage is enabled
- Ensure image domains are whitelisted in `next.config.ts`

### Authentication Issues

**Issue**: Login/signup not working
**Solution**:
- Verify `BETTER_AUTH_SECRET` is set and matches across all environments
- Ensure `NEXT_PUBLIC_SITE_URL` matches your deployed domain exactly
- Check browser console for CORS errors

### Slow Performance

**Issue**: Application loads slowly
**Solution**:
- Check Speed Insights for bottlenecks
- Verify images are being optimized (AVIF/WebP format)
- Enable Edge Caching in Vercel settings
- Consider upgrading Vercel plan for better performance

## 🔄 Continuous Deployment

Vercel automatically deploys when you push to your repository:

- **Production**: Pushes to `main` branch → Production deployment
- **Preview**: Pushes to other branches → Preview deployment
- **Pull Requests**: Each PR gets a unique preview URL

## 📈 Optimization Tips

### 1. Bundle Size Optimization

The project is configured with:
- Standalone output mode (smaller bundles)
- Tree-shaking enabled
- Console removal in production
- Package import optimization for common libraries

### 2. Caching Strategy

Configured caching:
- Static assets: 1 year cache
- Images: Immutable cache with AVIF/WebP
- API routes: No cache (always fresh)

### 3. Security Headers

Pre-configured security headers:
- Content Security Policy
- XSS Protection
- Frame Options
- HSTS (HTTP Strict Transport Security)
